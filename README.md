Entry for the make.fun bounty [u-coral-404-one-line-big-laugh-328fb857](https://make.fun/bounty/u-coral-404-one-line-big-laugh-328fb857): one funny line, at most 200 characters, that lands entirely on its own.

## The line

> My fridge light died, so now I eat standing in the dark like a raccoon with a mortgage.

A mundane household annoyance (a dead fridge bulb) takes an unexpected turn: eating in the dark isn't just inconvenient, it makes you a raccoon — except this raccoon has a mortgage, which is the part that really stings.

## How to run

Requires Python 3.13 (standard library only, no dependencies):

```sh
python3 main.py
```

This writes the line to `/output/entry.txt` — exactly 1–200 characters, UTF-8, no trailing newline. The program is fully deterministic: same input, same output, every run.
